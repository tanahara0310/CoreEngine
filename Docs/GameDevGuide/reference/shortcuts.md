# ショートカット

## ファイル

| キー | 何をするか |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | シーンを保存 |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> | スクリプトを再読み込み |
| <kbd>Alt</kbd>+<kbd>F4</kbd> | 終了 |

## 編集

| キー | 何をするか |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 取り消す |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> | やり直す |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | 複製 |
| <kbd>Del</kbd> | 削除 |

## ギズモ

| キー | モード |
|---|---|
| <kbd>W</kbd> | 移動 |
| <kbd>E</kbd> | 回転 |
| <kbd>R</kbd> | 拡縮 |
| <kbd>F</kbd> | 選んだものへカメラを寄せる |

## カメラ（Game ビューの上で）

| 操作 | やり方 |
|---|---|
| 回す | 中ボタンドラッグ |
| 平行移動 | <kbd>Shift</kbd> + 中ボタンドラッグ |
| 寄る・引く | ホイール |
| 視点を回す | 右ボタンドラッグ |
| 前後左右 | <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> |
| 下・上 | <kbd>Q</kbd> / <kbd>E</kbd> |
| 速く | <kbd>Shift</kbd> を足す |

!!! warning "<kbd>W</kbd> <kbd>E</kbd> <kbd>R</kbd> はギズモと共用です"
    右ドラッグでカメラを動かしている間だけ移動に使われます。

## Project ビュー

| キー | 何をするか |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | コピー |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | 切り取り |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | 貼り付け |
| <kbd>F2</kbd> | 名前を変える |
| <kbd>Del</kbd> | 削除（ごみ箱へ） |

## 画面

| キー | 何をするか |
|---|---|
| <kbd>Alt</kbd>+<kbd>Enter</kbd> | 全画面 |
| <kbd>F11</kbd> | エディタ UI を隠す（ゲーム画面だけ） |

## ゲーム側（既定）

| キー | 操作 |
|---|---|
| <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> / 方向キー | 移動 |
| <kbd>Space</kbd> | ジャンプ |
| <kbd>Shift</kbd> | ダッシュ |
| マウス左 | 攻撃 |
| <kbd>E</kbd> | インタラクト |
| <kbd>Esc</kbd> | ポーズ |

UI を選んでいる間は、方向キーで選択が移り、<kbd>Enter</kbd> で決定、<kbd>Esc</kbd> でキャンセルになります。

**割り当ては Help → キー操作を見る から変えられます。** → [入力アクション](input-actions.md)
