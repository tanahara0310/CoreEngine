# ヒエラルキーとインスペクタ

## ヒエラルキー

![ヒエラルキー](../assets/images/panel-hierarchy.png)

シーンにあるものが全部並びます。

| 操作 | やり方 |
|---|---|
| 選ぶ | クリック |
| 名前を変える | 名前をダブルクリック |
| 親子を開け閉め | 左の ▶ / ▼ |
| カメラを寄せる | 選んでから <kbd>F</kbd> |
| 複製 | <kbd>Ctrl</kbd>+<kbd>D</kbd> |
| 削除 | <kbd>Del</kbd> |

右端の **AS** の印は、そのオブジェクトにスクリプトが付いていることを表します。

### 増えても迷わないための仕組み

オブジェクトが数十個になると、一覧から探すのは無理になります。次の 3 つでカバーしています。

- **親子は入れ子で出ます。** 子は親の下に字下げして並ぶので、まとまりが見えます
- **Game ビューでクリックすると、ヒエラルキーの該当行まで自動でスクロールし、親も開きます。** 「画面のこれ、どれ？」が一発で分かります
- **<kbd>F</kbd> でカメラが寄ります。** 逆に「一覧のこれ、どこ？」も分かります

## インスペクタ

![インスペクタ](../assets/images/panel-inspector.png)

選んだオブジェクトの中身です。

### Object の行

| もの | 意味 |
|---|---|
| チェック | オブジェクト全体の有効・無効 |
| 名前 | ここでも変えられます |
| ⋮ | プレハブにする、などのメニュー |

### コンポーネントの行

各コンポーネントは折りたためます。左のチェックでそのコンポーネントだけ無効にできます。

!!! info "無効にすると何が止まるか"
    - スクリプト … `Update` などが呼ばれなくなり、当たり判定の通知も届かなくなります
    - 描画するもの … 描かれなくなります
    - コライダー … 当たらなくなります

    **付けたまま一時的に切る**のに使います。消すのとは違い、設定は残ります。

### 値の編集

| 型 | 見た目 |
|---|---|
| 数値 | 左右にドラッグで増減。ダブルクリックで直接入力 |
| 色 | 四角を押すとカラーピッカー |
| チェック | bool |
| 一覧 | 列挙（種類・向きなど） |
| アセット | ファイルを選ぶ欄。Project からドラッグでも入る |
| オブジェクト参照 | シーン内の別オブジェクトを選ぶ欄 |

項目名にカーソルを乗せると、説明（ツールチップ）が出るものがあります。

### スクリプトのコンポーネント

右上に**ファイル名の印**（`PhysicsLab.as`）が出ます。**スクリプトを開く**を押すと VS Code でそのファイルが開きます。

!!! warning "「読み込めない型」と出たら"
    ![読み込めない型](../assets/images/inspector-missing-type.png)

    スクリプトのコンパイルに失敗しているか、クラス名を変えたときに出ます。**保存データはそのまま持っている**ので、直せば元に戻ります。慌てて消さないでください。

    → [エラーの直し方](../script/errors.md)

## 取り消しとやり直し

| 操作 | キー |
|---|---|
| 取り消す | <kbd>Ctrl</kbd>+<kbd>Z</kbd> |
| やり直す | <kbd>Ctrl</kbd>+<kbd>Y</kbd> |

インスペクタでの編集、オブジェクトの追加・削除、ギズモでの移動が対象です。右下に回数が出ます。

!!! note "再生中の編集は取り消しの対象外です"
    再生を止めると、再生を始めた瞬間の状態へまとめて戻ります。
