# Project とアセット

![Project](../assets/images/panel-project.png)

## 画面の見方

| 場所 | 中身 |
|---|---|
| 上のパンくず | 今いるフォルダ（押すとその階層へ戻る） |
| 名前で絞り込み | 入れた文字を含むものだけ出す |
| すべて / モデル / テクスチャ / プレハブ / スクリプト / シーン / 音 / データ | 種類で絞る |
| 左のツリー | フォルダの階層 |
| 右の一覧 | 中身。グリッド表示と一覧表示を切り替えられる |

## 置き場所

```
Application/Assets/
├── Models/      モデル（.obj .fbx .gltf .glb）
├── Textures/    画像（.png .jpg .hdr）
├── Prefabs/     プレハブ（.prefab）
├── Scenes/      シーン（フォルダ 1 つで 1 シーン）
├── Scripts/     スクリプト（.as）
├── Physics/     物理マテリアル
└── Presets/     各種プリセット
```

音は好きな場所に置けますが、`Sounds/` のようなフォルダを作ってまとめておくと探しやすくなります。

!!! info "フォルダ構成は自由です"
    エンジンが決め打ちしているのは `Assets/Scripts`（スクリプトを探す場所）と `Assets/Scenes`（シーンを探す場所）だけです。その中の並べ方は自由です。

## ファイルを増やす

**エクスプローラでコピーするだけ**です。エディタが自動で見つけます。

見つからないときは Project ビューを開き直すか、フォルダを選び直してください。

## 操作

右クリック、またはキーで操作できます。

| 操作 | キー |
|---|---|
| コピー | <kbd>Ctrl</kbd>+<kbd>C</kbd> |
| 切り取り | <kbd>Ctrl</kbd>+<kbd>X</kbd> |
| 貼り付け | <kbd>Ctrl</kbd>+<kbd>V</kbd> |
| 名前を変える | <kbd>F2</kbd> |
| 削除 | <kbd>Del</kbd> |

**＋ 作成**から、フォルダとスクリプトを作れます。

!!! info "削除はごみ箱へ行きます"
    完全削除はしません。間違えて消してもごみ箱から戻せます。

!!! warning "触れるのは Assets の中だけです"
    エンジン本体のファイルは Project ビューから触れません。

## .meta ファイルは消さないこと

アセットの隣に `.meta` という同名ファイルができます。中に **GUID**（そのファイルを指す ID）が入っています。

**参照は GUID で保存されます。** だから、

- ファイルの**名前を変えても、場所を移しても、参照は切れません**
- `.meta` を消すと GUID が作り直され、**参照が全部切れます**

エディタの Project ビューから操作すれば `.meta` も一緒に動くので安全です。エクスプローラで動かすときは `.meta` も一緒に動かしてください。

## モデルを置く

Project ビューからモデルを **Game ビューへドラッグ**すると、そのモデルのオブジェクトができます。

テクスチャは **インスペクタのテクスチャ欄へ**ドラッグします。

## スクリプトを作る

**＋ 作成 → スクリプトを作成…**、または一覧の空きを右クリック。

| 雛形 | 中身 |
|---|---|
| **Basic** | `Start` と `Update` |
| **Collision** | `Start` `Update` と当たり判定の関数 |
| **Empty** | クラスだけ |

雛形は `Application/Config/ScriptTemplates/*.as.txt` にあります。**ファイルを足せば選択肢が増えます。** 中の `{CLASS}` がクラス名に置き換わります。

!!! warning "雛形の拡張子は必ず `.as.txt` です"
    `.as` にすると、雛形そのものがスクリプトとしてコンパイルされてしまいます。

## 置き場所の決まり

- クラス名は**プロジェクト全体で一意**である必要があります
- **ファイル名をクラス名と同じにしてください**（違うと警告が出ます）
- 1 ファイルに 1 クラスにしてください（複数あると警告が出ます）

ファイル名とクラス名を揃えておけば、ファイル名は重複しないので、クラス名の衝突も自動的に防げます。
