# CoreEngine でゲームを作る

このエンジンは **C++ を書かずにゲームが作れます。**

やることは 2 つだけです。

1. **エディタでオブジェクトを置き、コンポーネントを付ける**
2. **動きだけをスクリプト（AngelScript）で書く**

シーンもプレハブも設定も、全部ただの JSON ファイルです。ビルドし直さなくても、エディタで変えればその場で反映されます。

**オブジェクトは器です。** 中身はコンポーネントで決まります。

- 位置を持たせたい → `Transform`
- 形を出したい → `MeshRenderer`
- 落として転がしたい → `Rigidbody` と `Collider`
- 独自の動きをさせたい → **自分で書いたスクリプト**

Unity を触ったことがあれば、ほぼそのままの考え方です。

## 今できること・できないこと

**できること**

- 3D の描画（PBR・影・空・雲・霧・水面・ポストエフェクト）
- 物理（落ちる・跳ねる・転がる・積み上がる・キャラが歩く）
- アニメーション（スキニング・ブレンド）
- パーティクル（CPU / GPU）
- UI（画像・文字・ボタン・スライダー・トグル）
- 音（BGM・効果音・距離による減衰）
- 入力（キーボード・マウス・ゲームパッド 4 台）

**まだ無いこと**

- アニメーションのイベント（足音のタイミングをアニメから取る仕組み）
- 経路探索（NavMesh）
- 2D 専用の物理
- 文字の入力欄（名前を打ち込む UI）

無いものは、スクリプトで自分で書けば回避できます。たとえば足音は、アニメの再生時間を見て鳴らします。
