# 1. 玉を転がす

**この章でやること** — 玉を落として跳ねさせます。スクリプトはまだ書きません。

**かかる時間** — 10 分ほど

---

## シーンを作る

**File → 新しいシーン…** で名前を付けます（ここでは `BallTest` とします）。

新しいシーンには**床が最初から入っています**（`DefaultGround`）。当たり判定も付いているので、そのまま物を落とせます。

!!! note "床が要らないときは"
    シーンのフォルダにある `_scene.json` へ `"defaultGround": false` と書くと出なくなります。

## 玉を置く

**GameObject → 空のオブジェクトを作成**。名前を `Ball` にします。

インスペクタで **＋ コンポーネント追加**から、次の 4 つを足します。

### 1. MeshRenderer（形を出す）

`MeshRenderer` を足し、**モデル**の欄に球のモデルを入れます。

Project ビューで `Application/Assets/Models/Sphere/sphere.obj` を探し、**モデルの欄へドラッグ**するのがいちばん早いです。

### 2. Material（色を付ける）

`Material` を足します。

| 項目 | 入れる値 | 意味 |
|---|---|---|
| 色 | 好きな色 | 基本の色 |
| メタリック | `0.2` | 金属っぽさ（0 = 非金属、1 = 金属） |
| ラフネス | `0.45` | 表面のざらつき（0 = 鏡、1 = つや消し） |

### 3. Collider（当たり判定）

`Collider` を足し、**球**の形を 1 つ追加して半径を `1` にします。

!!! warning "コライダーの既定はトリガーではありません"
    **トリガー**のチェックが入っていると、すり抜けます。玉を跳ねさせたいので**外したまま**にしてください。

### 4. Rigidbody（物理で動かす）

`Rigidbody` を足します。

| 項目 | 入れる値 |
|---|---|
| 種別 | 動的 |
| 質量 | `1` |
| 重力を使う | ✓ |

最後に `Transform` の**位置**の Y を `5` にして、空中から落とします。

## 再生する

▶ を押すと、玉が落ちて床で止まります。

**まだ跳ねません。** 跳ね返りは次のコンポーネントで決まります。

## 跳ねさせる

`PhysicsMaterial` を足します。

| 項目 | 入れる値 | 意味 |
|---|---|---|
| 反発 | `0.7` | 跳ね返る強さ（0 = 跳ねない、1 = 減らずに跳ね続ける） |
| 摩擦 | `0.5` | すべりにくさ |

もう一度 ▶ を押すと、玉が跳ねます。

!!! tip "止まったように見えても計算は続きます"
    ほとんど動かなくなった物体は**眠り**ます（計算を止めます）。他の物がぶつかると起きます。眠っている数は `Physics::GetSleepingCount()` で見られます。

## 坂を作って転がす

**GameObject → 空のオブジェクトを作成**で `Slope` を作り、

1. `MeshRenderer` に板のモデル
2. `Collider` に**箱**を 1 つ（大きさは板に合わせる）
3. **静的**にチェックを入れる（動かない床や壁は必ずこれ）
4. `Transform` の**回転**の Z を `-0.3`（ラジアン）くらいにして傾ける

玉をその上へ持っていって再生すると、転がり落ちます。

!!! warning "動かない物に Rigidbody を付けないこと"
    床・壁・坂には `Rigidbody` を**付けません**。`Collider` の**静的**にチェックを入れるだけです。付けると落ちていきます。

## できあがったものを使い回す

`Ball` をヒエラルキーから Project ビューへドラッグすると **プレハブ**になります。以後は Project から何個でも置けます。

→ [プレハブ](../editor/prefab.md)

!!! example "見本がすでにあります"
    `Application/Assets/Prefabs/Physics/` に `PhysicsBall` `PhysicsBox` `PhysicsCapsule` があります。中身を見ると、ここで作ったものと同じ組み合わせになっています。

---

## この章のまとめ

- オブジェクトは器。**コンポーネントで中身を決める**
- 落として転がすには **`Collider` + `Rigidbody`**
- **動かない物は `Rigidbody` を付けず、`Collider` の静的にチェック**
- 跳ね返りと摩擦は **`PhysicsMaterial`**
