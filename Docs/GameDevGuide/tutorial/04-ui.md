# 4. 画面に出す

**この章でやること** — 集めた数を画面の隅に表示します。

**かかる時間** — 10 分ほど

## UI は Canvas ビューで組む

上のタブを **Game** から **Canvas** に切り替えます。UI だけが平面で見えるので、配置はこちらが楽です。

## 文字を置く

**GameObject → UI → テキスト** で作ります。名前は `ScoreLabel` にします。

### RectTransform の設定

| 項目 | 入れる値 | 意味 |
|---|---|---|
| アンカー | `左上` | **画面のどこを基準にするか** |
| 位置 | `(40, 40)` | 基準からのずらし（px） |
| 基準点 | `(0, 0)` | 自分のどこを位置に合わせるか |

!!! tip "アンカーは「画面が広がったときどこに残るか」"
    アンカーを `左上` にすると、ウィンドウを大きくしても左上からの距離が保たれます。スコアは左上、体力バーは下中央、といった使い分けをします。

    選べるのは `左上` `上中央` `右上` `左中央` `中央` `右中央` `左下` `下中央` `右下` の 9 つです。

### UIText の設定

| 項目 | 入れる値 |
|---|---|
| テキスト | `0 / 0` |
| フォントサイズ | `36` |
| 色 | 白 |
| 縁取りの色 | 黒 |
| 縁取りの太さ | `0.15` |

!!! note "縁取りは背景に負けないために要ります"
    明るい空の上に白い文字を置くと読めません。黒い縁取りを少し付けるだけで、どんな背景でも読めるようになります。

## スコアと繋ぐ

`ScoreKeeper.as` を書き換えて、数字を文字に反映します。

```cpp title="ScoreKeeper.as（書き換え）" hl_lines="6 7 20 21 22 29"
[DisplayName("スコア")]
class ScoreKeeper : ScriptComponent
{
    [ReadOnly] [Tooltip("集めた数")]
    int collected = 0;

    [ObjectRef] [Tooltip("数を出すテキスト")]
    GameObject@ label;   // (1)

    [Tooltip("全部集めたときに出す文字")]
    string clearMessage = "コンプリート！";

    private int total_ = 0;
    private UIText@ text_;

    void Start()
    {
        collected = 0;
        if (label !is null) {
            @text_ = label.uiText;   // (2)
        }
        Refresh();
    }

    void AddOne()
    {
        collected++;
        Refresh();
        if (total_ > 0 && collected >= total_) {
            if (text_ !is null) { text_.text = clearMessage; }   // (3)
        }
    }

    void Register()
    {
        total_++;
        Refresh();
    }

    private void Refresh()
    {
        if (text_ !is null) {
            text_.text = collected + " / " + total_;
        }
    }
}
```

1. インスペクタで繋ぎ先を選べるようになります。
2. 同じ書き方で、繋いだオブジェクトの `UIText` を取ります。
3. `text` に入れるだけで表示が変わります。

## 繋ぐ

1. `GameManager` を選ぶ
2. インスペクタの `ScoreKeeper` にある **数を出すテキスト**の欄を押す
3. 一覧から `ScoreLabel` を選ぶ

▶ で再生すると、コインを取るたびに左上の数字が増えます。

## 毎フレーム書き換えない

```cpp
// 悪い例：毎フレーム文字列を作り直す
void Update()
{
    text_.text = collected + " / " + total_;
}
```

文字列の組み立てとフォントの処理は、見た目より重い処理です。**値が変わったときだけ**書き換えてください。上の例で `Refresh()` を別関数にしているのはそのためです。

## 体力バーを作る

`UIImage` を 2 枚重ねると、伸び縮みするバーになります。

1. `HpBackground`（`UIImage`、暗い色、大きさ `400 x 24`）
2. `HpFill`（`UIImage`、赤、同じ位置・同じ大きさ、`描画順` を 1 つ大きく）

`HpFill` の `RectTransform` の**基準点**を `(0, 0.5)` にすると、**左端を固定したまま**幅を変えられます。

```cpp
void SetHp(float ratio)   // 0.0〜1.0
{
    RectTransform@ rect = fill.rectTransform;
    Vector2 size = rect.size;
    size.x = 400.0f * ratio;
    rect.size = size;
}
```

!!! tip "スライダーを使う手もあります"
    操作させたくないなら上の方法で十分です。プレイヤーに動かさせるなら `UISlider` を使います。→ [5. タイトルと設定](05-title.md)
