# EngineTests

エンジンの機能を 1 つずつ確かめるためのプロジェクトです。1 つの機能に 1 つのシーンを作ります。

- 形はエンジン組み込みの立方体・球・板だけを使います。モデルとテクスチャは入れません。
- 既定で入るもの（既定の床・空の環境光・雲・霧・自動露出・ローカル露出・ブルーム・レンズフレア）は、シーンの `_scene.json` と `_environment.json` で切ります。TAA・CAS は `Application/Config/EngineSettings/CVars.json` で切っています。AO（`r.SSAO.Enabled`）は既定のまま入れています（RTAO を確かめるため）。AO は空の環境光だけを暗くするので、空の環境光を切ったシーンには効きません。
- カメラは固定です。
- このプロジェクトでは組み合わせの不具合は見つかりません。確かめ終わったら、いつものシーン（アラハなど）も 1 回開いてください。

## RTShadow_LocalLights

点光源・スポット・エリアのレイトレーシングの影を確かめます（DXR 1.1 に対応した GPU が要ります）。

左から 5 灯並べています。どのライトの下にも 1m の箱（スポットは球）と細い柱があります。空の環境光を切っているので、影の中は真っ暗になります。

平行光源の無いシーンにはエンジンが既定の太陽を置くので、強さ 0・影を落とさない平行光源（NoDefaultSun）を置いて止めています。

| ライト | 見るところ |
|---|---|
| Point_Sharp | 光源の大きさ 0。箱と柱の影の縁がくっきりする |
| Point_Soft | 光源の大きさ 0.4m。同じ配置で、影の縁が離れるほどぼける |
| Spot | 外角 35 度。柱の影はコーンの外へ出ない |
| Area | 2m × 1m の発光面。柱の影が大きくぼける |
| Point_NoSlot | 5 灯目。影を落とす局所ライトは 4 灯までなので、カメラから最も遠いこのライトだけ影が無い |

確かめ方:

1. 4 灯に影があり、Point_NoSlot だけ影が無い。
2. Point_Sharp のインスペクタで「影を落とす」を外すと、Point_Sharp の影が消え、Point_NoSlot に影が付く。
3. ライトや箱を動かすと影が付いてくる。止めると数フレームで落ち着く。
4. レイトレーシングのデバッグ窓の影のタブに、局所ライトの行（点光源 0 など）が出る。
5. デバッグ窓の「中間結果」で、影の「生の値」（ざらつく）・「履歴」・「マスク」（なめらか）がライトごとに出る。影のノイズ取りは RTDenoiser（ほかの効果と共通の部品）が受け持つ。

## RTAO

レイトレーシングの環境光の遮り（RTAO）を確かめます（DXR 1.1 に対応した GPU が要ります）。

AO は空の環境光だけを暗くするので、このシーンは空の環境光を入れています。太陽の影の中は空の環境光だけで照らされるので、AO の差がいちばんよく見えます。

| 物 | 見るところ |
|---|---|
| Box・Ball | 床に接した根元のまわりが暗くなる |
| Corner_Back・Corner_Side | 壁の内側の隅（床との境目と縦の角）が暗くなる |
| Board_Low | 床から 0.3m 浮いた板。板の下がはっきり暗くなる |
| Board_High | 床から 1.5m 浮いた板。レイの長さ（`r.RTAO.Radius` の既定 1m）より遠いので、板の下の影は Board_Low の下より明るい |

確かめ方:

1. レイトレーシングのデバッグ窓の「概要」に「環境光の遮り（RTAO）」の行が出て、状態が撃てている（Dispatched）になる。
2. その行の「ON」を外すと SSAO に切り替わる。SSAO は画面に映った物しか見ないので、Board_Low の下や壁の隅の暗がりの形が変わる。
3. 「中間結果」で RTAO の「生の値」（ざらつく）・「履歴」・「AO」（なめらか）が出る。
4. Project Settings の Rendering Techniques で `r.RTAO.Radius` を 2 にすると、Board_High の下も暗くなる。`r.RTAO.Enabled` を外すと SSAO に、`r.SSAO.Enabled` を外すと AO が無くなる。
5. Box を動かすと暗がりが付いてくる。止めると数フレームで落ち着く。

## 画素デバッガ（レイの追跡）

レイトレーシングのデバッグ窓の「レイの追跡」で、選んだ 1 画素に効果が撃ったレイが出るかを確かめます。専用のシーンは作らず、上の 2 つのシーンを使います。

確かめ方:

1. RTShadow_LocalLights を開き、「レイの追跡」で「ゲーム画面で選ぶ」を押して、Point_Sharp の箱の影の中の床をクリックする。初めてのときは記録版のシェーダを作るので少し止まる。
2. 表に「影（点光源・枠 N）」の行が出て、そのライトへのレイの結果が「遮られた」、物の列が箱か柱になる。影の外の床を選ぶと「抜けた」になる。
3. ゲーム画面に、白いカメラのレイと、床からライトへ向かう効果の色の線が出る。「効果」で 1 つの影に絞ると、表と線がその影だけになる。
4. RTAO を開き、Board_Low の下の床を選ぶと「環境光の遮り（RTAO）」の行が出て、1m までのレイが板に「遮られた」になる。
5. RTAO.CS.hlsl の `RTRecordBeginPixel` の次の行へ一時的に `RT_DEBUG_PRINT(traceCoord);` を足し、エディタを開き直す。「シェーダの値（RT_DEBUG_PRINT）」に、選んだ画素のトレース解像度の座標（画面の座標の半分）と行番号が出る。確かめたら消す。
6. 水面のレイ（水のコースティクス・屈折・反射）は、このプロジェクトに水が無いので、アラハのシーンで水面を選んで確かめる。

## LightGizmos

シーンビュー（エディタの Game ビュー）に出るライトのアイコンと、選んだライトの届く範囲の線を確かめます。

4 種類のライトを 1 灯ずつと、コンポーネントを切った点光源を 1 灯置いています。

| ライト | 見るところ |
|---|---|
| Sun | 平行光源。右奥の太陽のアイコン。選ぶと光の進む向きの矢印が 5 本出る |
| Point | 点光源（橙・高さ 2m・届く距離 5m）。電球のアイコン。選ぶと半径 5m の球が出て、床に埋まった下半分は薄くなる |
| Spot | スポットライト（外角 35 度・内角 25 度・届く距離 6m）。アイコンは光の向きへ回る。選ぶと円すいと、内角の縁が薄い線で出る |
| Area | エリアライト（水色・2m × 1m・届く距離 5m）。アイコンは光の向きへ回る。選ぶと発光面の枠と、前側の半球が出る |
| Point_Disabled | Light のコンポーネントを切った点光源（赤）。アイコンが灰色になる |

確かめ方:

1. 5 つのアイコンがライトの位置に出て、色がライトの色（Point_Disabled だけ灰色）になる。床や物に隠れず、カメラを引いても同じ大きさのまま。
2. アイコンにカーソルを乗せると下に名前が出る。クリックするとそのライトが選ばれ、Hierarchy がその行までスクロールし、アイコンが大きくなって黄色の輪が付く。
3. 選んだライトにだけ範囲の線が出る。インスペクタで届く距離・角度・発光面の大きさ・向きを変えると線が付いてくる。Spot と Area は、向きを変えるとアイコンも回る。
4. 範囲の線は、床に埋まった所と物の後ろに回った所だけ薄くなる（アイコンは隠れない）。カメラを回しても、薄い所と濃い所の境目は床との交わりから動かない。Floor を選んで少し上げると、薄い所が増える。
5. 選んだまま移動のギズモの矢印をドラッグしても、アイコンのクリックにはならない。アイコンの無い所をクリックすると、いつものように物が選ばれる。
6. Point_Disabled を選ぶと、線も灰色で出る。コンポーネントを入れ直すと赤に戻る。
7. Console で `d.Light.Visualize 0` にすると、アイコンも線も消える。`1` で戻る。

届く距離は、光がちょうど 0 になる距離です。明るさは距離の 2 乗で弱まるので、床が目に見えて明るい所は球の線よりかなり内側になります（線が大きすぎるのではありません）。
