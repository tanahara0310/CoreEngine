# EngineTests

エンジンの機能を 1 つずつ確かめるためのプロジェクトです。1 つの機能に 1 つのシーンを作ります。

- 形はエンジン組み込みの立方体・球・板だけを使います。モデルは入れません。テクスチャは確かめる機能に要るときだけ、小さいものを `Application/Assets/Textures` に置きます（VolumetricFog_Shafts の穴の開いた板・VolumetricFog_Transparent の粒）。
- 既定で入るもの（既定の床・空の環境光・雲・霧・自動露出・ローカル露出・ブルーム・レンズフレア）は、シーンの `_scene.json` と `_environment.json` で切ります。TAA・CAS は `Application/Config/EngineSettings/CVars.json` で切っています。AO（`r.SSAO.Enabled`）は既定のまま入れています（RTAO を確かめるため）。AO は空の環境光だけを暗くするので、空の環境光を切ったシーンには効きません。
- カメラは固定です。
- このプロジェクトでは組み合わせの不具合は見つかりません。確かめ終わったら、いつものシーン（アラハなど）も 1 回開いてください。

## RTShadow_LocalLights

点光源・スポット・エリアのレイトレーシングの影を確かめます（DXR 1.1 に対応した GPU が要ります）。

左から 5 灯並べています。どのライトの下にも 1m の箱（スポットは球）と細い柱があります。空の環境光を切っているので、影の中は真っ暗になります。

平行光源の無いシーンにはエンジンが既定の太陽を置くので、強さ 0・影を落とさない平行光源（NoDefaultSun）を置いて止めています。

| ライト | 見るところ |
|---|---|
| Point_Sharp | 光源の大きさ 0。箱と柱の影の縁がくっきりする |
| Point_Soft | 光源の大きさ 0.4m。同じ配置で、影の縁が離れるほどぼける |
| Spot | 外角 35 度。柱の影はコーンの外へ出ない |
| Area | 2m × 1m の発光面。柱の影が大きくぼける |
| Point_NoSlot | 5 灯目。影を落とす局所ライトは 4 灯までなので、カメラから最も遠いこのライトだけ影が無い |

確かめ方:

1. 4 灯に影があり、Point_NoSlot だけ影が無い。
2. Point_Sharp のインスペクタで「影を落とす」を外すと、Point_Sharp の影が消え、Point_NoSlot に影が付く。
3. ライトや箱を動かすと影が付いてくる。止めると数フレームで落ち着く。
4. レイトレーシングのデバッグ窓の影のタブに、局所ライトの行（点光源 0 など）が出る。
5. デバッグ窓の「中間結果」で、影の「生の値」（ざらつく）・「履歴」・「マスク」（なめらか）がライトごとに出る。影のノイズ取りは RTDenoiser（ほかの効果と共通の部品）が受け持つ。

## RTAO

レイトレーシングの環境光の遮り（RTAO）を確かめます（DXR 1.1 に対応した GPU が要ります）。

AO は空の環境光だけを暗くするので、このシーンは空の環境光を入れています。太陽の影の中は空の環境光だけで照らされるので、AO の差がいちばんよく見えます。

| 物 | 見るところ |
|---|---|
| Box・Ball | 床に接した根元のまわりが暗くなる |
| Corner_Back・Corner_Side | 壁の内側の隅（床との境目と縦の角）が暗くなる |
| Board_Low | 床から 0.3m 浮いた板。板の下がはっきり暗くなる |
| Board_High | 床から 1.5m 浮いた板。レイの長さ（`r.RTAO.Radius` の既定 1m）より遠いので、板の下の影は Board_Low の下より明るい |

確かめ方:

1. レイトレーシングのデバッグ窓の「概要」に「環境光の遮り（RTAO）」の行が出て、状態が撃てている（Dispatched）になる。
2. その行の「ON」を外すと SSAO に切り替わる。SSAO は画面に映った物しか見ないので、Board_Low の下や壁の隅の暗がりの形が変わる。
3. 「中間結果」で RTAO の「生の値」（ざらつく）・「履歴」・「AO」（なめらか）が出る。
4. Project Settings の Rendering Techniques で `r.RTAO.Radius` を 2 にすると、Board_High の下も暗くなる。`r.RTAO.Enabled` を外すと SSAO に、`r.SSAO.Enabled` を外すと AO が無くなる。
5. Box を動かすと暗がりが付いてくる。止めると数フレームで落ち着く。

## 画素デバッガ（レイの追跡）

レイトレーシングのデバッグ窓の「レイの追跡」で、選んだ 1 画素に効果が撃ったレイが出るかを確かめます。専用のシーンは作らず、上の 2 つのシーンを使います。

確かめ方:

1. RTShadow_LocalLights を開き、「レイの追跡」で「ゲーム画面で選ぶ」を押して、Point_Sharp の箱の影の中の床をクリックする。初めてのときは記録版のシェーダを作るので少し止まる。
2. 表に「影（点光源・枠 N）」の行が出て、そのライトへのレイの結果が「遮られた」、物の列が箱か柱になる。影の外の床を選ぶと「抜けた」になる。
3. ゲーム画面に、白いカメラのレイと、床からライトへ向かう効果の色の線が出る。「効果」で 1 つの影に絞ると、表と線がその影だけになる。
4. RTAO を開き、Board_Low の下の床を選ぶと「環境光の遮り（RTAO）」の行が出て、1m までのレイが板に「遮られた」になる。
5. RTAO.CS.hlsl の `RTRecordBeginPixel` の次の行へ一時的に `RT_DEBUG_PRINT(traceCoord);` を足し、エディタを開き直す。「シェーダの値（RT_DEBUG_PRINT）」に、選んだ画素のトレース解像度の座標（画面の座標の半分）と行番号が出る。確かめたら消す。
6. 水面のレイ（水のコースティクス・屈折・反射）は、このプロジェクトに水が無いので、アラハのシーンで水面を選んで確かめる。

## LightGizmos

シーンビュー（エディタの Game ビュー）に出るライトのアイコンと、選んだライトの届く範囲の線を確かめます。

4 種類のライトを 1 灯ずつと、コンポーネントを切った点光源を 1 灯置いています。

| ライト | 見るところ |
|---|---|
| Sun | 平行光源。右奥の太陽のアイコン。選ぶと光の進む向きの矢印が 5 本出る |
| Point | 点光源（橙・高さ 2m・届く距離 5m）。電球のアイコン。選ぶと半径 5m の球が出て、床に埋まった下半分は薄くなる |
| Spot | スポットライト（外角 35 度・内角 25 度・届く距離 6m）。アイコンは光の向きへ回る。選ぶと円すいと、内角の縁が薄い線で出る |
| Area | エリアライト（水色・2m × 1m・届く距離 5m）。アイコンは光の向きへ回る。選ぶと発光面の枠と、前側の半球が出る |
| Point_Disabled | Light のコンポーネントを切った点光源（赤）。アイコンが灰色になる |

確かめ方:

1. 5 つのアイコンがライトの位置に出て、色がライトの色（Point_Disabled だけ灰色）になる。床や物に隠れず、カメラを引いても同じ大きさのまま。
2. アイコンにカーソルを乗せると下に名前が出る。クリックするとそのライトが選ばれ、Hierarchy がその行までスクロールし、アイコンが大きくなって黄色の輪が付く。
3. 選んだライトにだけ範囲の線が出る。インスペクタで届く距離・角度・発光面の大きさ・向きを変えると線が付いてくる。Spot と Area は、向きを変えるとアイコンも回る。
4. 範囲の線は、床に埋まった所と物の後ろに回った所だけ薄くなる（アイコンは隠れない）。カメラを回しても、薄い所と濃い所の境目は床との交わりから動かない。Floor を選んで少し上げると、薄い所が増える。
5. 選んだまま移動のギズモの矢印をドラッグしても、アイコンのクリックにはならない。アイコンの無い所をクリックすると、いつものように物が選ばれる。
6. Point_Disabled を選ぶと、線も灰色で出る。コンポーネントを入れ直すと赤に戻る。
7. Console で `d.Light.Visualize 0` にすると、アイコンも線も消える。`1` で戻る。

届く距離は、光がちょうど 0 になる距離です。明るさは距離の 2 乗で弱まるので、床が目に見えて明るい所は球の線よりかなり内側になります（線が大きすぎるのではありません）。

## WaterFoam

白波の泡を確かめます。いま砕けている波頭の泡と、砕けた後にその場へ残って消えていく泡の 2 つです。

風速 14m/s の外洋です。カメラは原点の高さ 20m から少し見下ろしています。

残る泡はゲームのカメラのまわりの 2 枚の格子に溜めます。近い方は 256m 四方を 25cm 刻み、遠い方は 1024m 四方を 1m 刻みです。その外は、格子の中で測った残りの泡の平均の濃さで塗ります。

確かめ方:

1. 再生して水面を選ぶ。インスペクタの水面の欄の下の「水面の可視化」で「泡の内訳」を選ぶ。赤（いま砕けている泡）が出た後ろに緑（残りの泡）が尾を引き、数秒かけて消える。緑は赤が出た所にだけ出る。
2. 「白波の割合」の実測が目標に近い（目標の 80〜100%）。「実測の内訳」で、残りが砕けている最中より多い。
3. 「泡が消えるまでの時間」を 10 にすると、緑の尾が長くなる。白波の割合の実測は目標のまま変わらず、内訳の砕けている最中が減る（全体の量が目標に合うように、砕ける量の方を減らす）。
4. MainCamera の高さを 150、下向き（Transform の回転 X）を 1.2 にする。泡が 127m ごと（FFT の 2 枚目の大きさ）に同じ形で並ばない。1km より先は平均の濃さで一様になり、格子の端に段が出ない。
5. MainCamera の位置 X を 100 ずつ動かす。泡は水面のその場に残り、カメラと一緒に動かない。
6. MainCamera の高さを 5、下向きを 0.6 にする。泡は大小の網目と房の形で、同じ形が規則的に並ばない。砕けた直後の泡は白く厚く、数秒たつと薄く透けた網目になって消えていく。
7. 6 の構図から高さを 20・150 と上げる。遠くの泡は網目から平均の濃さへなだらかに変わり、ちらつかない。
8. 6 の構図で「泡の内訳」を見る。緑の尾が消える速さが場所ごとに違う（同じ長さにそろわない）。

## Gizmo_ChildOfParent

親のあるオブジェクトをギズモで動かしたときに、親から見た値で動くかを確かめます。

| 物 | 見るところ |
|---|---|
| Parent | 橙の箱。位置・回転・拡大を初期値から変えてある |
| Child | 青の球。Parent の子（Parent から見て X に 2） |
| Grandchild | 緑の箱。Child の子（Child から見て Y に 2） |

確かめ方:

1. Child を選び、移動のギズモの矢印を少しずつドラッグする。球はマウスに付いてくるだけで、飛んだり速くなったりしない。インスペクタの位置は Parent から見た値（はじめは X 2・Y 0・Z 0）から少しずつ変わる。
2. 回転（E）・拡縮（R）のギズモでも、球はその場で回る・伸びるだけで、位置が変わらない。
3. Grandchild でも同じ。Child を動かすと Grandchild が付いてくる。
4. Ctrl+Z で動かす前に戻る。
5. インスペクタの数値の欄（ドラッグで変える欄）やコンボにカーソルを乗せると、欄がはっきり明るくなる（スライダーの欄と同じくらい）。

## Collider_DebugDraw

ツールバーの ◍ Collider の線が、停止中も出るかを確かめます。物はどれも床から 0.1m 浮かせてあり、重なっているのは Touch_A と Touch_B だけです。

| 物 | 形 | 停止中の線の色 |
|---|---|---|
| Floor | 箱（静止） | 緑 |
| Ball | 球 | 緑 |
| Crate | 箱（Y に回してある） | 緑 |
| Pill | カプセル | 緑 |
| Touch_A・Touch_B | 重なった 2 つの箱 | 緑（再生すると赤） |
| TriggerZone | トリガーの箱（見た目なし） | 青 |

確かめ方:

1. 停止のまま、ツールバーの ◍ Collider を押す。7 つの線が出る。もう一度押すと消える。
2. 停止のまま Crate をギズモで動かすと、線が付いてくる。Ball を削除すると線も消え、Ctrl+Z で戻すと線も戻る。
3. 再生すると Touch_A と Touch_B が赤になる。一時停止しても赤のまま。停止すると緑に戻る（停止で再生前のシーンへ戻るので、判定の結果も消える）。

## VolumetricFog_Basic

ボリュメトリックフォグ（カメラの近くの霧を 3D の格子で計算する）を確かめます。

高さフォグとボリュメトリックフォグを入れています。霧の濃さは 0.008（`r.Fog.Density`）です。太陽は右前の低い所（高さ約 15 度）にあり、カメラは太陽の方を向いています。

床の左右に高さ 8m の柱を 10m・25m・50m・100m・145m・155m・200m・300m に並べています。格子が届くのは 150m（`r.Fog.Volumetric.Distance`）までで、145m（左）と 155m（右）の柱はその境目をはさんでいます。

| 物 | 見るところ |
|---|---|
| 太陽のまわりの霧 | 太陽に近い方向ほど霧が明るく光る（`r.Fog.Volumetric.Anisotropy` の既定 0.6） |
| Pillar_145m・Pillar_155m | 格子の内と外。霧の掛かり方に段が無く、遠いほどなめらかに霞む |
| Pillar_300m | 格子の外。霧の色と明るさが、手前の格子の中の霧と同じ式で続く |

確かめ方:

1. Hierarchy の Environment を選ぶ。インスペクタの高さフォグに「ボリュメトリックフォグ」のチェックが入っていて、その下に「格子 160 x 90 x 64」（1920 × 1080 の画面のとき）が出る。
2. チェックを外すと今までの高さフォグに戻る。入れ直すと霧の色が太陽と空の光の色に変わり、太陽の側が明るく、反対側が暗くなる。
3. MainCamera の回転 Y を 3.14 にして太陽に背を向ける。霧は暗く、空の光の青みが強くなる。
4. 詳細設定の `r.Fog.Volumetric.Distance` を 50 にする。50m のあたりにも、145m と 155m の柱の間にも、霧の段が出ない。
5. Sun のインスペクタで光の向きを変える。霧の明るい所が太陽に付いてくる。強さを 0 にすると、霧は空の光だけで照らされる。
6. `r.Fog.Volumetric.DebugView` を変える。1 は格子の透過率（手前は白・遠いほど暗い）、2 は格子が足す光、3 は奥行きの区切り（色の帯。近いほど細かい）。0 で戻す。
7. `r.Fog.Volumetric.GridPixelSize` を 8 や 24 にすると、インスペクタの格子の数が変わる。ゲームの窓の大きさを変えても付いてくる。

DXR 1.1 に対応した GPU では、柱の陰の霧が暗くなります（物の影）。光の筋は VolumetricFog_Shafts で、雲の影は VolumetricFog_CloudShafts で、点光源・スポット・エリアライトの霧は VolumetricFog_LocalLights で確かめます。

## VolumetricFog_CloudShafts

ボリュメトリックフォグに雲の影が落ちることと、前のフレームと混ぜた霧に縞やざらつきが出ないことを確かめます。

高さフォグ（濃さ 0.01）とボリュメトリックフォグ（格子の距離 300m）と雲を入れています。雲の影が霧の範囲に入りやすいよう、雲を小さく（`r.Cloud.WeatherMapScale` 8000）、雲の影のマップの範囲を狭く（`r.Cloud.ShadowRegionSize` 10000）しています。太陽は右前の高さ約 40 度にあり、カメラは少し上を向いています。

床の左右に高さ 8m の柱を 20m・60m・120m・200m・300m に並べています。

| 物 | 見るところ |
|---|---|
| 床と霧 | 床が雲の影に入っている所では、その上の霧も同じように暗い（空の光だけの青い霧になる） |
| 柱 | 柱の陰の霧も暗くなる（物の影。VolumetricFog_Shafts で確かめる） |

確かめ方:

1. シーンを開く。雲の位置によって、手前一帯が雲の影に入って床と霧が青く暗いか、全部が日なたで白い。
2. Hierarchy の Environment を選び、ボリュメトリック雲の詳細設定「ゴッドレイ・雲影」の `r.Cloud.SceneShadowStrength` を 0 にする。手前が雲の影に入っていたときは、床が日なたになり、霧も白く明るくなる。1 に戻すと、床と霧が一緒に暗くなる。
3. 雲の「風速」を 100 m/s（上限）に上げる。雲の影が流れてきて、床の影の縁と一緒に、霧の明るい所と暗い所の境目が動いていく。終わったら 8 に戻す。
4. 高さフォグの詳細設定で `r.Fog.Volumetric.DebugView` を 4 にする。格子の奥の端（300m か、それより手前の床）での影が白黒で出る（白が日なた・黒が影。雲の影に柱の影が重なる）。0 で戻す。
5. 何も動かさずに霧を見る。縞やざらつきが出ない。`r.Fog.Volumetric.HistoryWeight` を 0 にしても、止まった絵はほとんど変わらない（前のフレームと混ぜた結果がずれていない）。0.9 に戻す。
6. MainCamera のインスペクタで回転 Y の値をドラッグして、カメラを左右に回す。霧の明るい所と暗い所が遅れて付いてきたり、残像が残ったりしない。
7. MainCamera の位置 Z を 100 にする（1 フレームで 10m 以上動かす）。前の位置の霧が残らない。

柱の陰の霧の暗さ（物の影）は VolumetricFog_Shafts で確かめます。

## VolumetricFog_Shafts

ボリュメトリックフォグに物の影が落ち、物の間から差す光が霧の中で筋になることを確かめます（DXR 1.1 に対応した GPU が要ります）。

高さフォグ（濃さ 0.015）とボリュメトリックフォグを入れています。雲・ブルーム・自動露出は切り、露出は EV 0 で固定しています。太陽はカメラの正面の奥の高さ約 22 度にあり、光は奥から手前へ進みます（逆光）。

| 物 | 見るところ |
|---|---|
| SlotWall_00〜05 | 奥 20m に並べた幅 3.4m・高さ 12m の柱。0.6m の隙間から差す光が、霧の中を手前へ伸びる筋になる |
| Fence_00〜11 | 手前 8m の細い板の柵。板の陰が霧の中に細い縞で出る |
| Lattice | 穴の開いた板（画像のアルファで抜けている。木の葉の代わり）。抜けた所から光が漏れ、霧の中に網目の筋が出る |
| Mover | 赤い箱。動かすと霧の中の影も付いてくる |

確かめ方:

1. シーンを開く。柱の隙間から手前へ光の筋が伸び、柱の陰の霧は暗い。
2. Sun のインスペクタで「霧に影を落とす」を外す。霧が一様に明るくなり、筋が消える（床の影は残る）。入れ直すと筋が戻る。
3. Sun の「霧を照らす強さ」を 0 にすると、霧は空の光だけの暗い霧になる。2 にすると霧が明るくなる。1 に戻す。
4. Mover の位置 X をインスペクタでドラッグして動かす。霧の中の箱の影が付いてくる。速く動かすと薄い尾を引く（前のフレームと混ぜる量 `r.Fog.Volumetric.HistoryWeight` 0.9 の遅れ。60fps で 0.2 秒に 7 割ほど追いつく）。HistoryWeight を 0.7 にすると尾が短くなり、霧のざらつきは少し増える。0.9 に戻す。
5. 高さフォグの詳細設定で `r.Fog.Volumetric.DebugView` を 4 にする。格子の奥の端（床）での影が白黒で出る。柱・柵・板の網目・箱の影が、床の影と同じ形で出る。5 にすると、太陽から見た深さの画像が画面の中央に正方形で出る（光の向きから見た絵なので左右は画面と逆。霧の範囲の光源側の端が黒・反対側の端と何にも当たらない所が白。物と床の差は小さく、柱と板は床の帯の上の端に小さく出る）。0 で戻す。
6. `r.Fog.Volumetric.ShadowResolution` を 256 にすると、柵の板の筋がぼけたり途切れたりする。1024 に戻す。
7. Window ▸ Rendering ▸ Ray Tracing の窓の「概要」に「霧の物の影（太陽から見た深さ）」の行が出て、解像度 1024 × 1024 とレイの数と GPU 時間が出る。GPU 時間は 0.15ms 以下が目安。その行の「ON」を外すと、2 と同じく筋が消える。「中間結果」の「太陽から見た深さ」で画像を見られる（範囲を狭めると柱や板がはっきり出る）。

DXR 1.1 に対応していない GPU では、物の影は霧に落ちません（雲の影だけ落ちます）。

## VolumetricFog_LocalLights

点光源・スポット・エリアライトがボリュメトリックフォグを照らすことを確かめます。

夜のシーンです（平行光源は強さ 0・空の明るさ 0 の NoDefaultSun だけ）。高さフォグ（濃さ 0.04・高さの減衰 0.05）とボリュメトリックフォグを入れ、霧の色（`r.Fog.Color`）を暗くしているので、ライトの近く以外の霧はほとんど黒です。雲・ブルーム・自動露出は切り、露出は EV 2 で固定しています。

| 物 | 見るところ |
|---|---|
| StreetLamp | 高さ 4.85m の下向きのスポット（内側 25 度・外側 40 度）。霧の中に光の円錐が出て、床の光の輪とつながる |
| Lantern | 青い点光源（高さ 1.3m）。まわりの霧が丸く光り、離れるほど暗くなる |
| Window | 壁の窓のエリアライト（1.6m × 1.2m・カメラの方を向く）。窓の正面の霧が光の帯になる |
| NoFog | 手前の赤い点光源。「霧を照らす強さ」が 0 なので、床は赤く照らすが、まわりの霧は光らない |

確かめ方:

1. シーンを開く。街灯の下に光の円錐、ランタンのまわりに青い丸い光、窓の前に光の帯が霧の中に出る。手前の赤い点光源は床だけを照らす。
2. Hierarchy の Environment を選ぶ。高さフォグの「ボリュメトリックフォグ」の下に「霧を照らす点光源・スポット・エリア 3 灯」が出る（NoFog は霧を照らさないので数えない）。
3. 詳細設定の `r.Fog.Volumetric.LocalLights` を外す。円錐・丸い光・光の帯が消えて霧が黒くなり、床の照らされ方は変わらない。入れ直す。
4. StreetLamp の「霧を照らす強さ」を 0 にすると円錐だけが消え、3 にすると円錐が明るくなる。1 に戻す。NoFog の「霧を照らす強さ」を 1 にすると、赤い点光源のまわりの霧も光る。0 に戻す。
5. StreetLamp の「外側の角度」を 20 にすると、霧の円錐も床の光の輪も一緒に細くなる。40 に戻す。
6. Lantern の位置 X をインスペクタでドラッグして動かす。霧の丸い光が付いてくる（前のフレームと混ぜるので、速く動かすと少し尾を引く）。
7. MainCamera の位置を Lantern の 1m 手前（X 0.5・Y 1.3・Z 8）にする。光源のまわりの霧が、格子の形に白く尖ったりちらついたりしない。

点光源・スポット・エリアライトは霧に影を落としません（壁の向こうの霧も照らします）。

## VolumetricFog_Transparent

半透明の物・水面・パーティクルにも、不透明の物と同じボリュメトリックフォグが掛かることを確かめます。

高さフォグ（濃さ 0.01）とボリュメトリックフォグを入れています。太陽は右前の低い所（高さ約 15 度）にあり、カメラは太陽の方を向いています（VolumetricFog_Basic と同じ）。雲・ブルーム・自動露出は切り、露出は EV 0 で固定しています。風は 3 m/s にして、水面の波を低くしています。

| 物 | 見るところ |
|---|---|
| Opaque_010m〜Opaque_300m・Glass_010m〜Glass_300m | 10m・25m・50m・100m・145m・155m・220m・300m に、不透明の箱（左）と半透明の箱（右。アルファ 0.99・合成は「通常」）を並べています。同じ距離の 2 つは、霧の色と濃さが同じに見える |
| Glass_145m・Glass_155m | 格子の内（145m）と外（155m）。格子の外でも、隣の不透明の箱と同じ霧が掛かる |
| Water | 右手前の池（一辺 100m・FFT の海を切った Gerstner の波）。奥ほど、まわりの床と同じ霧に霞む |
| Particles_020m・Particles_080m | 左の 2 つの噴水（加算の粒。再生中だけ出る）。80m の粒は 20m の粒より霧に薄れる |

確かめ方:

1. シーンを開く。どの距離でも、左右の箱の霧の掛かり方が同じ（右の半透明の箱だけ暗く沈んだり、白く浮いたりしない）。
2. Hierarchy の Environment を選び、高さフォグの「ボリュメトリックフォグ」を外す。どちらの箱も今までの高さフォグの色になり、左右は同じまま。入れ直す。
3. Sun の「霧を照らす強さ」を 3 にする。霧が明るくなり、半透明の箱と水面も、隣の不透明の箱と床と同じだけ明るい霧に包まれる。1 に戻す。
4. Glass_050m の Material の色のアルファを 0.4 にする。箱の向こうの床が透け、箱の縁に明るい線や暗い線が出ない。0.99 に戻す。
5. 再生する。左の 2 つの噴水から粒が出て、80m の粒は 20m の粒より霧に薄れる。停止する。

格子はゲームのカメラで作るので、Scene のタブ（シーンビュー）の半透明の箱と水面は、今までの高さフォグの式で描きます。
