## 7-A : SSR（Screen Space Reflection）

### 目的

Planar Reflection（Step 4）は水面しか映せないが、  
SSR はスクリーン上のすべてのピクセル情報を使うためより汎用的な反射を実現できる。  
また、RTT の追加解像度コストなしに細かい反射ディテールが得られる。

### アルゴリズム

```
1. 水面ピクセルの法線から反射レイ方向を計算
   reflect_dir = reflect(-viewDir, normal)

2. ビュー空間で反射レイをスクリーン空間に投影

3. Ray Marching（粗いステップで進む）
   ループ: 現在位置の深度と深度バッファの値を比較
   ray の深度 > バッファの深度 → 大まかな交差点発見

4. Binary Search で交差点をより正確に絞り込む

5. 交差点のカラーバッファ色を反射色として使用
   ※ 画面外に出る場合はキューブマップでフォールバック
```

### 使用技術

| 技術名 | 役割 |
|--------|------|
| **Screen Space Reflection（SSR）** | スクリーン上のピクセル情報を使った反射。Planar Reflection より汎用的で、波による細かい反射ディテールも表現できる |
| **Depth Buffer（深度バッファ）** | 各ピクセルの深度値を格納したバッファ。Ray Marching の交差判定に使用 |
| **G-Buffer（ジオメトリバッファ）** | 法線・深度などを別テクスチャに書き込む。Deferred Rendering の中間バッファ。SSR に必要な情報を保持する |
| **Binary Search（二分探索）** | Ray Marching で大まかに交差点を見つけた後、より正確な交点を二分探索で絞り込む最適化手法 |
| **環境マップフォールバック** | 画面外に交差点がある場合にキューブマップで補完し、端のアーティファクトを隠す |

## 7-B : Caustics（コースティクス）

### 目的

水面で屈折した光が水底や水中に作る揺れる光のパターン（コースティクス）を表現する。  
水中シーンの最も印象的なビジュアル要素のひとつ。

### アルゴリズム

```
低コスト版（テクスチャアニメーション）:
  - 事前生成したコースティクステクスチャを時間でアニメーション
  - 2 枚を異なる速度でスクロールして min ブレンドすることで交差する光条を作る
  - 実装コストが低く、十分な見た目を得られる

高精度版（Photon Mapping / Ray Tracing）:
  - 光線を水面から水底に向かって追跡し、集光・分散パターンを計算
  - Compute Shader で実装可能だが高コスト
  - オフライン・プリレイク向け
```

### 使用技術

| 技術名 | 役割 |
|--------|------|
| **Caustics（コースティクス）** | 水面で屈折した光が水底に作る揺れる光のパターン。水中表現の最も特徴的な視覚効果 |
| **Caustics Texture Animation** | 事前生成したコースティクステクスチャを時間でアニメーション。2 枚を min ブレンドすることで交差する光条を作る |
| **Shadow Map Caustics** | シャドウマップを応用してリアルタイムコースティクスを実現する手法。水面から屈折レイを延ばして集光テクスチャを生成する |

## 7-C : Foam（泡・白波）

### 目的

波が崩れる箇所（砕波）に泡・白波を発生させる。  
Step 6 の FFT Ocean と組み合わせることで、Jacobian から物理的に正確な泡位置を特定できる。

### アルゴリズム

```
Jacobian ベースの泡検出（FFT Ocean 連携）:
  1. FFT 変位の偏微分から Jacobian を計算
  2. Jacobian 値が閾値以下（< 0）になった箇所 → 波が崩れていると判定
  3. その箇所に泡テクスチャをアルファブレンドする

Foam Accumulation（蓄積と消散）:
  - 泡は発生後、時間とともに蓄積・消散するサイクルを Compute Shader で管理
  - 前フレームの値に新たな泡を加算し、一定速度で減衰させることで自然な消え方を表現
```

### 使用技術

| 技術名 | 役割 |
|--------|------|
| **Foam（フォーム）** | 波の砕波点に発生する泡・白波の表現 |
| **Jacobian 判定** | FFT 変位のヤコビアン行列式が閾値以下になった箇所を泡エリアとして判定する物理的に正確な手法 |
| **Foam Texture Blend** | 判定した泡エリアに白い泡テクスチャをアルファブレンドする |
| **Foam Accumulation** | 泡の発生・蓄積・消散を管理するテクスチャ。Compute Shader で前フレームの値に新たな泡を加算し、一定速度で減衰させる |

## 7-D : Depth Fade & Sub-surface Scattering（詳細版）

Step 5 で近似実装したものをより精度高く実装する。

### 深度フェード（精度向上版）

```
改善点:
  - 線形深度ではなく対数深度を使い、遠方の精度を確保する
  - 浅瀬・深海の色を別々に設定し、深度で lerp する
  - 泡・波頭との合成順序を正しく管理する
```

### Sub-surface Scattering（精度向上版）

```
改善点:
  - 波高さだけでなく光の透過距離も考慮する
  - 複数の散乱色（浅いターコイズ → 深い青）をグラデーションで合成する
  - ライト方向と視線方向の両方を考慮した散乱計算にする
```

## 実装優先度の目安

SSR・Caustics・Foam は独立しているため、見た目のインパクトが高いものから取り組むとよい：

```
優先度 高: Foam（Jacobian なしのテクスチャ版から始められる）
優先度 中: Caustics（テクスチャアニメーション版なら低コスト）
優先度 低: SSR（実装コストが最も高いが反射品質は最も高い）
```

---

## 確認ポイント

- [ ] 波頭・砕波箇所に泡が発生している（Foam）
- [ ] 泡が時間とともに自然に消えている（Foam Accumulation）
- [ ] 水底に揺れる光のパターンが見える（Caustics）
- [ ] 水面の反射が波の細かい揺らぎを反映している（SSR）
- [ ] 画面端での反射アーティファクトが目立たない（SSR フォールバック）
