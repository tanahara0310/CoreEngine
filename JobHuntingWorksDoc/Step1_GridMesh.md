# Step 1 : グリッドメッシュの生成と表示

> **状態:** ✅ 完了  
> **目的:** 水面の土台となる `N × N` 分割の平面ポリゴンを生成し、単色でレンダリングする  
> **位置付け:** このメッシュが以降すべてのステップの土台になるため、分割数を最初に決める

---

## 目標

- 格子状に頂点を並べた平面メッシュを生成する
- `resolution`（分割数）を変数として持ち、後から変更できる設計にする
- 頂点データには **座標・UV・法線** の 3 要素を持たせる
- Index Buffer を使って重複頂点を削除する

---

## アルゴリズム

### 頂点配置

```
(0,3)-(1,3)-(2,3)-(3,3)
  |     |     |     |
(0,2)-(1,2)-(2,2)-(3,2)
  |     |     |     |
(0,1)-(1,1)-(2,1)-(3,1)
  |     |     |     |
(0,0)-(1,0)-(2,0)-(3,0)

N = resolution の場合:
  頂点数        : (N+1) × (N+1)
  三角形数      : N × N × 2
  インデックス数 : N × N × 6
```

各頂点の座標・UV は以下のように計算する：

```
position.x = -size/2 + (i / N) * size
position.z = -size/2 + (j / N) * size
position.y = 0.0f

uv.x = i / N
uv.y = j / N
```

### インデックス生成（クワッドを 2 三角形に分割）

```
頂点インデックス番号の対応:
  (i,   j+1) --- (i+1, j+1)
      |               |
  (i,   j  ) --- (i+1, j  )

三角形 1: (i,j), (i, j+1), (i+1, j+1)
三角形 2: (i,j), (i+1, j+1), (i+1, j)
```

---

## 使用技術

| 技術名 | 役割 |
|--------|------|
| **Grid Mesh（グリッドメッシュ）** | 格子状に頂点を並べた平面ポリゴン。分割数が高いほど後のステップで波の表現が細かくなる |
| **Vertex Buffer** | GPU に頂点データ（座標・UV・法線）を渡すバッファ |
| **Index Buffer** | 頂点の描画順（三角形の組み合わせ）を定義するバッファ。重複する頂点データを削除できる |
| **Input Layout** | 頂点シェーダーに渡す頂点構造体のメモリレイアウト定義 |

---

## D3D12 実装上の注意点

- **Vertex Buffer / Index Buffer は GPU 専用ヒープ（`D3D12_HEAP_TYPE_DEFAULT`）に配置する**  
  CPU から直接書けないため、Upload ヒープを中間バッファとして使い `CopyBufferRegion` で転送する
- **`D3D12_VERTEX_BUFFER_VIEW` / `D3D12_INDEX_BUFFER_VIEW` の `StrideInBytes` と `Format` に注意する**  
  インデックスは `DXGI_FORMAT_R32_UINT`（32bit）か `DXGI_FORMAT_R16_UINT`（16bit）を選択する
