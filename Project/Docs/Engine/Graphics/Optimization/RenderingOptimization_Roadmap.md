# レンダリング最適化・軽量化ロードマップ

作成日: 2026-07-23
対象: CoreEngine レンダリングパイプライン全体

## 1. 目的

カメラ内にシーンの全オブジェクトが入った状態（近距離・全部見え）でも 60fps に貼り付かせる。
視錐台カリング・LOD・インスタンシングは「描く物の数と遠景の密度を減らす」施策であり、
**全オブジェクトが近距離で画面内にある状況では原理的に効かない**。この状況で効くのは以下の3系統。

1. 画面内でも実際には見えていない三角形を描かない（オクルージョン系）
2. 1三角形あたりのコストを下げる（ジオメトリ構造系）
3. 1ピクセルあたりのコストを下げる(解像度・シェーディング系)

## 2. 現状分析（2026-07-23 時点）

### 計測済みの事実
- ボトルネックは **G-Buffer ラスタライズの三角形数バウンド**（A/B テストで確定）
- 主因は地形メッシュ（`Terrain_Terrain_1` 等の巨大サブメッシュ）
- 平面反射ビューの二重描画は反射ゲート修正・DXR 移行で対処済み

## 3. 施策一覧と優先順位

### A. 三角形バウンドに直撃する施策（優先度: 高）

#### A-1. Hi-Z オクルージョンカリング ← **実装中（本ロードマップの最初の施策）**
- 概要: 深度バッファから階層深度ピラミッド（Hi-Z）を構築し、オブジェクト AABB を
  コンピュートシェーダーで遮蔽判定。遮蔽されたオブジェクトは次フレーム以降描画をスキップ。
- 効果: カメラ内でも手前の地形・建物の裏にある物を描かない。フラスタムカリングでは取れない削減。
- 詳細設計: [HiZOcclusionCulling_Design.md](HiZOcclusionCulling_Design.md)

#### A-2. クアッドツリー / クリップマップ地形
- 概要: 一枚岩の地形メッシュをタイル分割し、タイルごとに距離依存解像度で描画（CDLOD 方式）。
- 効果: 近距離でカメラ内に地形全体が入っても、視点から遠いタイルは粗いまま。
  `Terrain_Terrain_1` のような「簡略化不能サブメッシュ」問題の根本解決。
- 備考: Hi-Z のタイル単位カリングとも相性が良い（タイル AABB がそのまま遮蔽判定単位になる）。

#### A-3. メッシュレット（クラスタ）カリング
- 概要: メッシュを 64〜128 三角形のクラスタに分割し、クラスタ単位で
  バックフェース・錐台・遮蔽カリング。`meshopt_buildMeshlets`（組み込み済みの meshoptimizer）で生成可能。
- 効果: 「1メッシュが巨大」なモデルをクラスタ単位で細かく落とせる。
  Mesh Shader（DX12 Ultimate）または ExecuteIndirect で実装。
- 備考: A-1 の Hi-Z ピラミッドをそのまま流用してクラスタ遮蔽判定に使える。

### B. ピクセル・解像度系の施策（優先度: 中）

#### B-1. 動的解像度スケーリング + アップスケール
- 概要: 内部レンダリング解像度を 70〜80% に落とし最終段でアップスケール
  （初期実装はバイリニア＋シャープン、将来 FSR2 系）。フレームタイム監視で自動調整。
- 効果: ライティング・水面・雲・ポストプロセスのコストが解像度比例で減少。
  「60fps 貼り付き」を仕組みとして保証できる最も汎用的な手段。三角形バウンド部分には効かない。

#### B-2. 可変レートシェーディング（VRS）
- 概要: 画面周辺部・低コントラスト領域を 2x2 レートでシェーディング。
- 効果: 中程度。B-1 の後で十分。

#### 注意: Z-prepass は非推奨
現状は三角形数バウンドのため、頂点を2回流す Z-prepass は逆効果になり得る。
ピクセルシェーダーバウンドに転じた場合のみ再検討。

### C. パス構成・時間方向の施策（優先度: 中）

#### C-1. 副次ビューの品質分離
反射ビュー・シャドウビューに、より強い LOD バイアス（+2）、短い描画距離カット、
オブジェクト種別フィルタ（小物は反射に描かない）を適用。

#### C-2. 静的シャドウのキャッシング
動かないオブジェクトのシャドウマップをキャッシュし、動的オブジェクトのみ毎フレーム上書き。
CSM 遠段カスケードの更新を 1/2〜1/4 フレームレートに間引き。

#### C-3. 重い画面系エフェクトのテンポラル分散
ボリューメトリック雲・ゴッドレイ・FFT 海面（3カスケード FFT 更新）を
半解像度＋テンポラル再構成、または隔フレーム更新化。

#### C-4. 非同期コンピュート
FFT・GPU パーティクル・LUT 生成をコンピュートキューへ移し、G-Buffer ラスタと並行実行。
三角形バウンドで固定機能が詰まっている間の ALU 空きを活用。
