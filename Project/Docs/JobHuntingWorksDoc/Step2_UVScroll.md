# Step 2 : 時間変化と位相管理

## ステータス
- 状態: 実装完了（検証継続）
- 優先度: 高
- 依存ステップ: Step 1
- 現在位置: `elapsedTime` と UV スクロール更新は実装済み。水面主線で共通時間源として使用中
- 完了後に着手しやすい次ステップ: Step 3, Step 7, Step 8

## 目的
波、屈折、泡、コースティクスに共通する時間基盤を整え、単なる UV スクロールではなく、複数現象が同じ時間系で同期する状態を作る。

## このステップの作業範囲
- フレーム時間の受け渡し
- グローバル位相の管理
- 補助 UV オフセットの定義
- 時間依存ノイズや補助アニメーションの同期方法
- 長時間実行時の数値安定性

## このステップで扱う責務
- GPU へ時間情報を渡す
- 波面位相と補助アニメーションを分離管理する
- 長時間実行でも破綻しにくい時間系を作る
- 後続ステップが共通利用できる time source を定義する

## このステップの役割
従来の水面表現では UV スクロールは「動いて見せるための簡易演出」で終わりやすい。  
しかし物理ベース水面では、時間は以下を同期させる基盤になる。

- Gerstner Wave の位相進行
- 表面の補助ゆらぎ
- 泡の発生と移動
- コースティクスのアニメーション
- 屈折オフセットの時間変化

## 作業項目
- [x] `time` を GPU に毎フレーム渡す
- [x] `elapsedTime` と `deltaTime` の役割を分ける
- [x] 波面位相と見た目補助用 UV スクロールを分離する
- [x] 時間依存ノイズを共通時間系から導出できる構造を持たせる
- [x] 長時間実行時の値の折り返し方針を決める

## 実施結果
- `WaterPlaneObject::UpdateUVScroll()` で `elapsedTime_` を積算し、波位相用の `waterCB_.time` を毎フレーム更新している
- UV オフセットは `scrollSpeed * deltaTime` で更新し、`fmod` により 0〜1 へ折り返している
- `WaterTestScene::OnUpdate()` から `deltaTime` を渡す流れができている
- `ApplyUVTransform()` により、UV タイリングとスクロールがマテリアルの `uvTransform` に反映される

## 物理ベース観点
### 1. 波の運動は UV ではなく幾何変位で表現する
- 主役となる波面変化は Step 3 の波面変位が担う
- Step 2 はその前提となる時間進行と補助信号の整理を担当する

### 2. UV スクロールは「水そのもの」ではない
- テクスチャが流れることと、水面が移動することは同義ではない
- そのため UV スクロールは補助信号として位置付ける

### 3. 時間の一貫性が重要
- 波、泡、コースティクス、屈折の更新時間がばらつくと説得力が落ちる
- すべての時間依存要素を同じ基準時間で駆動する

## 実装要素
| 要素 | 内容 |
|------|------|
| Frame time | 毎フレームの経過時間 |
| Global phase | 波や泡の位相管理 |
| UV transform | 補助ノイズや流れ表現のオフセット |
| Wrap / repeat | 長時間実行時の安定性確保 |
| Shared time source | 泡・コースティクス・屈折との同期 |

## 実装時の観点
- `elapsedTime` と `deltaTime` を分けて扱う
- UV オフセットは補助量として定義し、主変位と混同しない
- 波の位相進行は波長、速度、方向から導出する
- 時間依存ノイズは同じ基準時間に従わせる

## 期待する到達状態
- 波面、泡、コースティクスが同じ時間系で動く
- UV スクロールが主運動を代用せず、補助表現に留まる
- 長時間起動でも不連続ジャンプが目立たない

## 完了条件
- [x] GPU に時間が毎フレーム渡る
- [x] UV オフセットと波の位相進行が分離されている
- [x] 長時間駆動でも値が破綻しない
- [x] 後続の泡・コースティクス・屈折が同じ時間系を参照できる基盤がある
