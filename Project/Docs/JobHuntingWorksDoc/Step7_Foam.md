# Step 7 : Foam

> **状態:** 設計更新済み  
> **目的:** 波の崩れ、岸際、障害物交差部で発生する泡を、物理寄りの発生条件で追加する  
> **位置付け:** 水面のエネルギー散逸や接触表現を補うステップ

---

## このステップの役割

泡は単なる白線ではなく、
- 砕波
- 岸際の攪拌
- 障害物との衝突
- 高曲率 / 高圧縮の波面

に由来する現象として扱う。

---

## 目標

- 深度差や交差部から岸際泡を出す
- 高曲率・高圧縮から砕波泡の候補を取る
- 泡の寿命、移動、消散を時間で制御する
- 水面色や反射を壊さずに重ねる

---

## 物理ベース観点

### 1. 泡は散逸の結果
泡は水面そのものの色ではなく、乱れた空気混入層の見え方である。  
そのため、常時べったり乗せるのではなく、発生条件を持たせる。

### 2. 泡の出すぎは物理破綻に見える
- 湖で常時白波は不自然
- 深場中央に強い泡は不自然
- 交差部と高エネルギー部を中心に限定する

### 3. 近景の説得力に大きく効く
泡は少量でも、水際や障害物との接触を強く説明できる。

---

## 実装要素

| 要素 | 内容 |
|------|------|
| Shore foam mask | 岸際 / 接触部の泡 |
| Crest foam mask | 高曲率・高圧縮波面の泡 |
| Temporal foam evolution | 発生・移動・減衰 |
| Noise breakup | 泡輪郭の単調さ除去 |
| Foam compositing | 反射・透過を壊しすぎない重ね方 |

---

## 完了条件

- [ ] 岸際や障害物近傍に説得力のある泡が出る
- [ ] 深場中央で泡が過剰に出ない
- [ ] 泡に寿命と時間変化がある
- [ ] 泡が水面全体を白く汚さない
