# Step 7 : Foam

## ステータス
- 状態: 未着手
- 優先度: 中
- 依存ステップ: Step 3, Step 6, Step 6B
- 現在位置: 設計のみ。現行コードに shore foam / crest foam / temporal foam の実装は未確認
- 完了後に着手しやすい次ステップ: Step 8, Step 10

## 目的
波の崩れ、岸際、障害物交差部で発生する泡を、物理寄りの発生条件で追加し、水面のエネルギー散逸や接触説得力を補う。

## このステップの作業範囲
- 岸際 / 接触部の泡マスク
- 砕波 / 高曲率 / 高圧縮由来の泡候補抽出
- 泡の寿命、移動、減衰
- ノイズによる輪郭分断
- 反射・透過を壊しすぎない合成方法

## このステップで扱う責務
- 泡の発生条件を物理寄りに制限する
- 泡を時間発展する効果として扱う
- 近景説得力を上げつつ深場の過剰表現を防ぐ
- 水面色や反射経路と競合しない重ね方を決める

## このステップの役割
泡は単なる白線ではなく、
- 砕波
- 岸際の攪拌
- 障害物との衝突
- 高曲率 / 高圧縮の波面

に由来する現象として扱う。

## 作業項目
- [ ] 深度差や交差部から岸際泡を出す
- [ ] 高曲率・高圧縮から砕波泡の候補を取る
- [ ] 泡の寿命、移動、消散を時間で制御する
- [ ] 水面色や反射を壊さずに重ねる
- [ ] 深場中央で泡が出すぎない抑制条件を入れる

## 現状メモ
- 現在の水面シェーダーや定数バッファに foam mask、foam intensity、foam noise などの項目は存在しない
- Step 3 の波面情報と Step 6 の深度差は泡実装の入力候補として利用できる状態にある

## 物理ベース観点
### 1. 泡は散逸の結果
泡は水面そのものの色ではなく、乱れた空気混入層の見え方である。  
そのため、常時べったり乗せるのではなく、発生条件を持たせる。

### 2. 泡の出すぎは物理破綻に見える
- 湖で常時白波は不自然
- 深場中央に強い泡は不自然
- 交差部と高エネルギー部を中心に限定する

### 3. 近景の説得力に大きく効く
泡は少量でも、水際や障害物との接触を強く説明できる。

## 実装要素
| 要素 | 内容 |
|------|------|
| Shore foam mask | 岸際 / 接触部の泡 |
| Crest foam mask | 高曲率・高圧縮波面の泡 |
| Temporal foam evolution | 発生・移動・減衰 |
| Noise breakup | 泡輪郭の単調さ除去 |
| Foam compositing | 反射・透過を壊しすぎない重ね方 |

## 実装時の観点
- 泡は白ベタではなく、水面下の情報を多少残す合成を優先する
- Step 2 の時間基盤と Step 3 / Step 6B の波面情報を入力として使う
- 水際や障害物近傍を可視化できる debug mask があると調整しやすい

## 期待する到達状態
- 岸際や障害物近傍の接触説得力が増す
- 砕波候補が時間変化を伴って現れたり消えたりする
- 深場中央が不自然に白く汚れない

## 完了条件
- [ ] 岸際や障害物近傍に説得力のある泡が出る
- [ ] 深場中央で泡が過剰に出ない
- [ ] 泡に寿命と時間変化がある
- [ ] 泡が水面全体を白く汚さない

## 引き継ぎメモ
- Step 8 では泡の白さがコースティクスや水中光と競合しないかを見る必要がある
- Step 10 では泡マスク、発生条件、寿命を可視化できると調整しやすい
