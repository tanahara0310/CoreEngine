# Step 3 : Gerstner Wave と解析法線

## ステータス
- 状態: 実装完了（検証継続）
- 優先度: 最優先
- 依存ステップ: Step 1, Step 2
- 現在位置: Gerstner Wave、解析偏微分、再構成法線、プリセット再生成まで実装済み
- 完了後に着手しやすい次ステップ: Step 4, Step 5, Step 6, Step 7

## 目的
手続き的な波面変位と、その波面から一貫して導出される解析法線を整え、近景水面の主たる形状と反射・透過計算の入力を作る。

## このステップの作業範囲
- Gerstner Wave による頂点変位
- 複数波の重ね合わせ
- 接線・従法線の偏微分計算
- 解析法線の再構成
- 波パラメータの構造化

## このステップで扱う責務
- 近景水面の見た目の主運動を定義する
- 法線をノーマルマップ依存ではなく波面から導く
- Fresnel、反射、屈折、泡が使う法線入力を供給する
- 後続の FFT Ocean 分岐と役割分担を明確にする

## このステップの役割
物理ベース水面で最初に整えるべき主役は、
**色付き平面ではなく、連続した波面形状と法線** である。

この波面は最終的に以下へ波及する。

- Fresnel の角度依存
- Planar Reflection の見え方
- IBL の反射分布
- 泡の発生条件
- 水面下の屈折方向

- [x] 複数波の合成パラメータを定義する

## 実施結果
- `Water.VS.hlsl` で最大 16 本の Gerstner Wave を加算し、ワールド空間で頂点変位を行っている
- `CalcGerstnerWave()` で `dPdX` / `dPdZ` を求め、接線・従法線から解析法線を再構成している
- `WaterConstantBuffer.h` に波パラメータ構造とプリセット生成用のレイヤー設定が定義されている
- `WaterTestScene` にはプリセットベースの波再生成と個別波編集用 ImGui が実装されている
- 雷着弾による局所波紋も VS 側で重畳され、同じ法線再構成へ統合されている

## 物理ベース観点
### 1. 波面と法線は同じ数式から導出する
- 変位は Gerstner、法線は別ノーマルマップ、という分離は避ける
- 同じ波面から導くことで反射と屈折の整合を保つ

### 2. 波の階層を意識する
- 大波: シルエットと大局変形
- 中波: 反射の揺らぎ
- 小波: 表面細部

### 3. 近景説得力を優先する
- 波数を増やすこと自体が目的ではない
- 近景で反射・屈折が自然に追従することを優先する

## 実装要素
| 要素 | 内容 |
|------|------|
| Gerstner displacement | XYZ の波面変位 |
| Wave superposition | 複数波の重ね合わせ |
| Analytic derivatives | 偏微分による接線 / 従法線の導出 |
| Reconstructed normal | cross による解析法線 |
| Structured wave parameters | 波長・振幅・速度・方向・鋭さの管理 |

## FFT Ocean との関係
この Step は近景水面の主線であり、FFT Ocean を否定するものではない。  
**Step 6B (FFT Ocean)** は大規模海面向けの発展経路として扱い、近景の主線はまず Gerstner Wave で固める。

## 実装時の観点
- 波パラメータは後で UI から調整しやすい構造にする
- 法線再構成は PBR 入力としてそのまま使える形式に揃える
- 変位量と法線の整合が崩れないよう、片方だけを後付けで差し替えない
