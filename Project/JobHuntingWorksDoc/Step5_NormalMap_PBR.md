# Step 5 : Procedural Surface + PBR（近景の質感づくり）

> **状態:** 🔄 進行中  
> **目的:** プログラムで生成した波面情報と PBR パラメータの調整で、近景でも破綻しにくい水面の質感を作る  
> **位置付け:** Step 4 までで「動いて反射する水」は完成。Step 5 では「近景で見ても水らしい」表面情報を整える

---

## このステップで行うこと

1. **手続き波面の密度調整** — Gerstner Wave の重ね合わせとパラメータ調整で表面情報量を作る
2. **PBR パラメータの微調整** — 湖・池・プール・雨水など用途別に Roughness / Metallic / IBL を調整する
3. **波面由来の陰影の適正化** — 強すぎる陰影や反射でプラスチック状に見えないようにする
4. **表面密度感の確認** — 近景で見たときに繰り返しや荒さが目立たないようにする
5. **次ステップへの分離** — Fresnel / Depth Fade / 浅瀬色 / 法線再整合は Step 6 で扱う前提に整理する

---

## 1. 手続き波面の密度調整

水面は完全にプログラムで組み立てる方針なので、表面情報はノーマルマップではなく波の重ね合わせで作る。  
波数・振幅・波長・速度・方向の分布を調整し、近景で見たときに平坦すぎず荒れすぎない状態を狙う。

```
考え方:
  1. 大波・中波・小波で役割を分ける
  2. 方向のばらつきを持たせる
  3. 近景で見える細かさは小波側で作る
  4. 振幅を上げすぎず、鏡面反射を壊しすぎない範囲に抑える
```

---

## 2. PBR パラメータの調整

用途別の推奨値（ImGui で実験して最適値を探すこと）：

| 用途 | Roughness | Metallic | IBL 強度 | 特徴 |
|------|-----------|----------|----------|------|
| 湖（静かな水） | 0.02〜0.05 | 0.0 | 1.0 | 鏡面に近く周囲が映り込む |
| 海（波が立つ水） | 0.05〜0.15 | 0.0 | 1.0 | やや荒れた表面感 |
| 池・プール | 0.01〜0.03 | 0.0 | 1.2 | 非常に鏡面的で透明 |
| 雨水・水たまり | 0.03〜0.08 | 0.0 | 0.8 | やや曇り感のある反射 |

---

## 3. 波面由来の陰影の適正化

手続き波面だけでも、陰影や反射が強すぎると水ではなくビニールやプラスチックのように見える。  
この段階では以下の確認を優先する。

```
確認観点:
  1. ハイライトが粒立ちすぎていないか
	2. 小波が速すぎてノイズ状に見えないか
  3. 波方向の分布が不自然な反復を生んでいないか
  4. 波変位と反射の強さが喧嘩していないか
```

---

## 4. 表面密度感の確認

このステップでは「水面の情報量を増やす」ことが目的であり、
反射率や深さ表現の調整はまだ主目的ではない。  
そのため、以下の状態になっていれば十分とする。

- 近景で静止して見ても平坦すぎない
- 波パターンの反復が目立ちすぎない
- PBR ハイライトが水らしい滑らかさを保っている

---

## 5. Step 6 へ送る項目

以下はこのステップでは触れず、Step 6 でまとめて扱う。

- Fresnel の見直し
- 法線再整合
- Depth Fade
- 浅瀬 / 深場の色分離

---

## 使用技術

| 技術名 | 役割 |
|--------|------|
| **Layered Gerstner Waves** | 複数の波を重ね合わせて表面情報量を作る |
| **Directional Wave Distribution** | 波の方向ばらつきで反復感を減らす |
| **PBR（Physically Based Rendering）** | Metallic / Roughness / AO / IBL による物理ベースの光計算 |

---

## 確認ポイント

- [ ] 複数波の重ね合わせで近景の表面情報量が確保できている
- [ ] ImGui で Roughness を上げると反射がぼやける
- [ ] 近景で見ても波パターンの反復が目立ちすぎない
- [ ] 強すぎる陰影や反射でプラスチック状に見えない
