# Step 5 : 表面 BRDF/BTDF と材質校正

> **状態:** 設計更新済み  
> **目的:** 水面を PBR 材質として扱うための表面反射特性を整理し、後続の透過・吸収と整合する土台を作る  
> **位置付け:** 近景の質感づくりではなく、物理ベース水面の表面モデルを定義するステップ

---

## このステップの役割

ファイル名に `NormalMap_PBR` とあるが、主線はノーマルマップではない。  
このステップでは **水面を PBR 的にどう扱うか** を整理する。

対象は以下。

- roughness の意味付け
- F0 の基準値
- IBL と Planar Reflection の役割分担
- 手続き波面法線を BRDF にどう接続するか
- alpha や色を「見た目の都合」で使いすぎないこと

---

## 目標

- 水の F0 を屈折率由来の低反射率として扱う
- roughness を反射ローブの広がりとして整理する
- metallic は水では 0 を基本とする
- 手続き波面法線をそのまま PBR ライティングへ接続する
- 透過・吸収・屈折は次ステップへ送る前提で、表面側の責務を明確化する

---

## 物理ベース観点

### 1. 水は金属ではない
- `metallic = 0` を基準とする
- 鏡面的に見えるのは金属だからではなく、表面が滑らかで Fresnel が効くからである

### 2. F0 は屈折率から決まる
- 水の屈折率は約 1.33
- 空気との境界では F0 はおよそ 0.02 前後になる
- ここを演出都合で大きくしすぎると、常時鏡面の不自然な水になる

### 3. roughness は表面粗さの近似
- roughness を下げると鏡面反射が鋭くなる
- roughness を上げると反射ローブが広がる
- 近景で不自然なプラスチック感が出ない範囲を探る

### 4. ノーマルマップ前提にしない
- 近景水面の主法線は Step 3 の解析法線
- ノーマルマップが必要なら補助として後で検討するが、主線には置かない

---

## 実装要素

| 要素 | 内容 |
|------|------|
| F0 calibration | 水の基準反射率の設定 |
| Roughness tuning | 反射ローブの広がり調整 |
| Metallic discipline | 水を非金属として固定 |
| Analytic normal to PBR | 波面法線を BRDF に接続 |
| Reflection source separation | IBL / Planar / 後続 SSR の役割整理 |
