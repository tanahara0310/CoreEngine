# Step 7 : Foam（岸際の泡）

> **状態:** ⬜ 未着手  
> **目的:** 水と地形の接点に泡を追加し、水際が単調な切れ目に見える問題を改善する  
> **位置付け:** 水面品質では白波ではなく、岸際中心の控えめな泡を優先する

---

## このステップで行うこと

1. **Foam マスク生成** — 深度差や交差領域から泡の出る場所を特定する
2. **泡線の描画** — 水際に沿って細い泡を乗せる
3. **泡量の調整** — 海の砕波のように過剰にならないよう抑える
4. **時間変化の追加** — ノイズやスクロールで生きた泡に見せる

---

## 1. 泡の発生位置

水面品質では、まず岸際やオブジェクト接触部にだけ泡が出れば十分な効果がある。

```
候補:
  - sceneDepth と waterDepth の差が小さい領域
  - 水面と地形の交差領域
  - 波高や法線変化が大きい箇所を補助条件に使う
```

---

## 2. 泡の見せ方

泡は白一色をそのまま貼るより、ノイズで切った細い線として見せた方が自然になる。

- 細い岸際ラインを優先
- ぼかしすぎない
- 強度は浅瀬限定で高める
- 深場にはほぼ出さない

---

## 3. 使用技術

| 技術名 | 役割 |
|--------|------|
| **Foam Mask** | 泡を表示する領域を特定するマスク |
| **Depth Intersection Detection** | 水面と地形の接点を見つける |
| **Noise Texture Animation** | 泡の輪郭を単調に見せないための時間変化 |
| **Alpha Blend** | 泡を水面上に自然に重ねる |

---

## 確認ポイント

- [ ] 水際が単調な切れ目に見えない
- [ ] 泡が海の白波のように出すぎない
- [ ] 深場では泡がほぼ出ない
- [ ] Foam マスクをデバッグ表示できる
