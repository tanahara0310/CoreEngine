# Step 8 : Caustics（浅瀬の揺れる光）

> **状態:** ⬜ 未着手  
> **目的:** 浅い水底に揺れる光の模様を加え、浅瀬の説得力を上げる  
> **位置付け:** 水面品質では主役ではなく補助演出。浅瀬限定で効かせる

---

## このステップで行うこと

1. **簡易 Caustics テクスチャ** — 低コストなアニメーション表現を導入する
2. **浅瀬限定適用** — 深場にまで均一に出さない
3. **地面への投影** — 水底オブジェクトに揺れる光を乗せる
4. **強度調整** — 水面より目立ちすぎないようにする

---

## 1. 低コストな実装方針

まずはテクスチャアニメーション版で十分。

```
実装案:
  - Caustics テクスチャを 2 枚用意
  - 異なる速度でスクロール
  - min / multiply / add などで交差する光条を作る
  - depthFade や浅瀬判定と組み合わせて適用量を制御
```

---

## 2. 浅瀬限定にする理由

Caustics は浅い場所ほど見えやすい。  
深い場所でも同じ強さで出すと不自然になる。

- 浅瀬色が見える領域と相性が良い
- 深場では減衰させる
- Foam より目立たせない

---

## 3. 使用技術

| 技術名 | 役割 |
|--------|------|
| **Caustics Texture Animation** | 揺れる光模様を低コストに再現する |
| **Depth-based Attenuation** | 水深に応じてコースティクスを弱める |
| **Projected Lighting Approximation** | 水底への投影光として見せる簡易表現 |

---

## 確認ポイント

- [ ] 浅い場所でのみ揺れる光が見える
- [ ] 深場では目立たない
- [ ] 地面側に光の揺れが出る
- [ ] Caustics マスクや強度をデバッグ表示できる
