# Step 9 : SSR（補助反射）

> **状態:** ⬜ 未着手  
> **目的:** Planar Reflection だけでは拾いにくい画面内ディテールを補完し、反射密度を上げる  
> **位置付け:** 水面品質では主役ではなく補助反射。破綻時に無効化しやすい設計を優先する

---

## このステップで行うこと

1. **SSR の追加** — 画面内情報を使った補助反射を実装する
2. **Planar Reflection とのブレンド** — 主反射を壊さず不足分だけ補う
3. **フォールバック整理** — 失敗時は Planar / IBL に戻す
4. **品質確認** — 画面端や欠損時の破綻を抑える

---

## 1. SSR の基本アルゴリズム

```
1. 法線と視線から reflect_dir を求める
2. ビュー空間 / スクリーン空間で Ray Marching
3. 深度バッファとの交差判定
4. 必要なら Binary Search で交点を詰める
5. ヒット位置のカラーを反射色に使う
6. 失敗時は Planar Reflection または IBL にフォールバック
```

---

## 2. 水面品質での扱い

SSR は強力だが、画面外情報を拾えず破綻もしやすい。  
そのため、水面品質では以下の役割に限定する。

- 近接オブジェクトの反射密度を少し上げる
- 細かな波反射の補助に使う
- 主反射は常に Planar Reflection を優先する

---

## 3. 使用技術

| 技術名 | 役割 |
|--------|------|
| **Screen Space Reflection** | スクリーン上の情報から反射を再構成する |
| **Ray Marching** | 深度バッファ内で反射レイを進める |
| **Binary Search** | ヒット位置の精度を上げる |
| **Fallback Blending** | SSR の失敗時に Planar Reflection / IBL へ戻す |

---

## 確認ポイント

- [ ] 近接物の映り込み密度が増す
- [ ] 画面端の破綻が過剰でない
- [ ] 無効化時でも基本の見た目が成立する
- [ ] SSR 単体表示やヒット率をデバッグできる
