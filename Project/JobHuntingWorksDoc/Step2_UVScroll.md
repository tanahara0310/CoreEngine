# Step 2 : 時間変化と位相管理

> **状態:** 設計更新済み  
> **目的:** 波、泡、コースティクス、屈折ゆらぎに共通する時間基盤を整える  
> **位置付け:** 単なる UV スクロールではなく、水面内の時変要素を一貫して管理するための基礎ステップ

---

## このステップの役割

従来の水面実装では UV スクロールは「流れて見せるための簡易演出」で終わりやすい。  
しかし物理ベース水面では、時間は以下を同期させる基盤になる。

- Gerstner Wave の位相進行
- 表面の微細ゆらぎ
- 泡の寿命と移動
- コースティクスのアニメーション
- 屈折ゆらぎの時間変化

---

## 目標

- `time` を GPU に毎フレーム供給する
- 位相進行と見た目用スクロールを分離して管理する
- UV 変化を「材質の流れ」ではなく「補助的な時変信号」として扱う
- 将来的な屈折・泡・コースティクスでも同一時間系を参照できるようにする

---

## 物理ベース視点での整理

### 1. 波の主運動は UV ではなく幾何変位で表現する
- 大局的な波面運動は Step 3 の波面変位が担う
- Step 2 の役割は、主運動を補助する位相・ゆらぎ管理

### 2. UV スクロールは「流体そのもの」ではない
- テクスチャが流れることと、水塊が移動することは同義ではない
- そのため、UV スクロールは補助信号と位置付ける

### 3. 時間の一貫性が重要
- 波だけ進み、泡やコースティクスだけ止まる状態は避ける
- すべての時変要素を同じ基準時間から派生させる

---

## 実装要素

| 要素 | 内容 |
|------|------|
| Frame time | 毎フレームの経過時間 |
| Global phase | 波や屈折の位相管理 |
| UV transform | 補助的な流れやノイズアニメーション |
| Wrap / repeat | 長時間実行時の精度維持 |
| Shared time source | 泡・コースティクス・屈折との同期 |

---

## 推奨方針

- `elapsedTime` と `deltaTime` を分けて扱う
- UV オフセットは内部状態として持ち、周期的に折り返す
- 波の位相進行は波長・速度から計算し、単なるスクロール速度に置き換えない
- 時間依存のノイズは波と独立に持ちつつ、同じ時間系から導出する

---

## 完了条件

- [ ] GPU に時間が毎フレーム渡る
- [ ] UV オフセットと波の位相が整理されている
- [ ] 長時間動作でも値が破綻しない
- [ ] 後続の泡・コースティクス・屈折が同じ時間系を参照できる
