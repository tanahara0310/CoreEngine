# Step 6 : Surface Shading（法線再整合 + Fresnel + Depth Fade + 浅瀬色）

> **状態:** ⬜ 未着手  
> **目的:** 波形・反射・透明感・水深色を整合させ、近景で破綻しにくい水面の基礎品質を作る  
> **位置付け:** Step 5 で増やした表面情報を、水らしい見え方に結び付ける重要ステップ

---

## このステップで行うこと

1. **波変位後の法線再整合** — 頂点変位とライティングのズレを減らす
2. **Fresnel の見直し** — 正面では透け、斜めでは反射が立つ水らしい角度変化を作る
3. **Depth Fade** — 水深に応じた透明感を与える
4. **浅瀬色 / 深場色の分離** — 深さで水色を切り替え、浅い場所の説得力を上げる
5. **受け入れ基準の整備** — 以降の Foam / Caustics / SSR の土台となる見た目基準を作る

---

## 1. 波変位後の法線再整合

Gerstner Wave で頂点が動いていても、法線が平面前提のままだとハイライトが不自然になる。  
そのため、変位後の接ベクトルから法線を再構成するか、近似補正を行う。

```
考え方:
  1. 波の偏微分 dP/dx, dP/dz を求める
  2. 接ベクトル tangent / binormal を作る
  3. cross(binormal, tangent) で法線を再計算する
  4. ノーマルマップ法線と合成する
```

---

## 2. Fresnel の見直し

水面では視線角度によって見え方が大きく変わる。  
真上からは水中が見えやすく、斜めからは反射が強く見える必要がある。

```
// 水の屈折率は約 1.33
// Schlick 近似では F0 ≈ 0.02 が基準
F0 = 0.02f
fresnel = F0 + (1.0 - F0) * pow(1.0 - saturate(dot(N, V)), 5.0)
```

### 確認したい見え方

- 真上視点で水中や浅瀬色が見える
- 斜め視点で反射が強く立つ
- ガラス板のような常時反射にはならない

---

## 3. Depth Fade

シーン深度と水面深度の差から水深を求め、浅い場所は透明寄り、深い場所は不透明寄りにする。

```
アルゴリズム:
  1. 深度テクスチャから sceneDepth を取得
  2. 水面ピクセルの深度との差分で waterDepth を求める
  3. depthFade = saturate(waterDepth * absorptionCoeff)
  4. alpha や色補間に使う
```

### 実装上の要点

- 深度バッファを SRV として参照可能にする
- 必要に応じて線形深度化する
- デバッグ表示で depthFade 係数を可視化する

---

## 4. 浅瀬色 / 深場色の分離

水は単色ではなく、水深に応じて色が変化する。  
浅瀬では明るい青緑、深場では暗い青を基本とする。

```
float depthT = saturate(waterDepth * colorFadeScale);
float3 waterTint = lerp(shallowColor, deepColor, depthT);
```

### 目的

- 岸際の透明感を出す
- 深場の重さを出す
- 池 / 湖 / プールで色プロファイルを分けやすくする

---

## 5. 使用技術

| 技術名 | 役割 |
|--------|------|
| **Normal Reorientation / Recompute** | 頂点変位後の法線を整合させ、ライティング破綻を減らす |
| **Schlick Fresnel** | 視線角度による反射率変化を近似する |
| **Depth Fade** | 深度差から透明感と吸収感を制御する |
| **Beer-Lambert 近似** | 水深による光吸収の強まりを表現する |
| **Depth-based Color Lerp** | 浅瀬色と深場色を深さに応じて補間する |
